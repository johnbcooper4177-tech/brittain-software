Brittain Software Hospitality SMS Opt-In Script

Public verbal opt-in script for Brittain Software hospitality SMS messages.

Last updated: June 18, 2026

Agent Or Voice Assistant Script

Before sending any SMS, the agent or voice assistant reads:

"Brittain Software can text you the requested hospitality information for [property name], such as reservation details, booking or checkout links, property information, addresses, parking details, and support replies. Message frequency varies, usually 1-2 messages per reservation or information request. Message and data rates may apply. Reply HELP for help or STOP to opt out. Do I have your permission to send this text? Please say yes or no."

Consent Handling

SMS is sent only if the guest says yes. Consent is recorded with opt-in method, timestamp, phone number, requested property, and opt-out status.

This SMS program is used only for requested hospitality customer-care messages. Brittain Software does not send marketing or promotional SMS messages under this opt-in flow. Consent is not a condition of purchase.
