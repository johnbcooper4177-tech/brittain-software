# Brittain Software Website

Static one-page website for Brittain Software.

## Run locally

```bash
python3 -m http.server 4177
```

Then open `http://127.0.0.1:4177`.

## Public Site

The public site is published with Cloudflare Pages direct uploads at:

```text
https://brittainsoftware.com/
```

Release procedure: [Cloudflare Pages](docs/operations/cloudflare-pages-release.md). GitHub Pages is a secondary copy; merging to main does not update the public Cloudflare site.
